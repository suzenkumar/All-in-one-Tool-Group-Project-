Server-side Gemini key
This app calls Google's free Gemini API through its own backend (/api/generate). The API key lives only in Vercel's environment variables (as GEMINI_API_KEY) and is never sent to the browser — nothing to paste here. To set it up, get a free key at aistudio.google.com/apikey, add it in your Vercel project under Settings → Environment Variables, and redeploy.
